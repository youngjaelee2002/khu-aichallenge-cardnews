# AI 카드뉴스 자동 제작기

행사 정보와 사진만 넣으면, 단체가 쓰는 피그마 디자인 양식 그대로 인스타그램 카드뉴스(1080×1350)를 만들어 주는 웹 기반 도구입니다.
AI(Claude)가 사진 속 글자까지 읽어 문구와 구성을 쓰고, 결과는 PNG 이미지로 받거나 버튼 하나로 피그마 템플릿에 자동으로 채울 수 있습니다.

▶ **시연 영상:** https://youtu.be/rRXQPqcibh0

경희대학교 교육혁신사업단 학생기획단이 사업단의 행사와 활동을 알리는 카드뉴스를 더 쉽고 빠르게 만들기 위해 제작했습니다.

## 왜 만들었나요

학생회, 학과, 동아리, 사업단까지 학교 안의 거의 모든 단체가 인스타그램 카드뉴스로 소식을 알립니다.
그런데 카드뉴스 한 세트를 만들려면 자료를 읽고, 장마다 문구를 쓰고, 사진을 고르고, 디자인 툴에서 글과 사진을 하나씩 옮겨 붙여야 합니다.
디자인 양식은 이미 정해져 있는데도 이 반복 작업에 매번 시간이 들고, 디자인 툴에 익숙하지 않은 사람은 참여하기 어렵습니다.

이 도구는 반복 작업을 AI와 자동화에 맡기고, 사람은 **무엇을 어떻게 알릴지 기획하고 다듬는 일**에 집중할 수 있게 합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| **AI 자동 작성** | 행사 정보와 사진(활동 사진, 포스터·안내문 캡처)을 넣으면 표지 제목·해시태그, 속지 장 수, 장별 소제목·본문, 구성, 사진 배치까지 작성 |
| **사진 속 글자 읽기** | 포스터·안내문·시간표 사진에서 행사명, 일시, 장소, 프로그램 등을 읽어 문구에 반영 |
| **템플릿 그대로 재현** | 피그마 템플릿(표지·속지·마무리)의 좌표·색·글꼴을 그대로 옮겨, 누가 만들어도 같은 디자인 |
| **실시간 미리보기·편집** | 글을 고치면 실제 크기 미리보기가 즉시 바뀜. 장 수·구성·사진 위치·확대를 자유롭게 조정 |
| **PNG / ZIP 저장** | 인스타그램 규격(1080×1350) PNG를 장별로 또는 한 번에 ZIP으로 저장 |
| **피그마 자동 생성** | "피그마로 보내기"를 누르면 피그마 플러그인이 템플릿을 복제해 글·사진을 채움. 결과는 편집 가능한 피그마 레이어 |

## 사용 방법

### 1. 실행

**`카드뉴스 제작기 실행.bat`** 을 더블클릭합니다.
검은 창(로컬 서버)이 뜨고 브라우저에서 http://localhost:8765 가 열립니다. **검은 창은 쓰는 동안 켜 두세요.**

> 직접 실행하려면 폴더에서 `python server.py`

### 2. 피그마 플러그인 켜 두기

피그마 템플릿 파일에서 **카드뉴스 가져오기**를 실행합니다.
창에 **초록 점과 "웹 제작기와 연결됨"** 이 보이면 준비 완료입니다.

### 3. 정보와 사진 넣고 AI로 작성

1. 웹 상단 **AI 자동 작성** 칸의 **정보**에 행사명, 일시, 장소, 내용, 강조할 점을 자유롭게 적습니다.
2. **사진** 칸에 활동 사진과 포스터·안내문 캡처를 끌어다 놓습니다. (정보 칸을 비워 두고 사진만 넣어도 됩니다)
3. **Claude API 키**를 펼쳐 키를 넣고 **AI로 자동 작성**을 누릅니다. 사진이 많으면 30초~1분 걸립니다.

AI 없이 쓰려면 이 단계를 건너뛰고 아래 장별 칸에 직접 입력하면 됩니다.

### 4. 확인하고 다듬기

장마다 미리보기와 편집 칸이 나옵니다. 문구·구성·사진을 확인하고 필요한 부분을 고칩니다.
미리보기에서 사진을 끌면 위치가 바뀝니다.

### 5. 내보내기

- **피그마로 보내기**: 피그마에 `카드뉴스 자동생성 (날짜·시간)` 섹션이 생기고, `01_표지`, `02_속지1` … 순서로 채워집니다.
- **전체 PNG 받기 (ZIP)**: 모든 장을 PNG로 한 번에 받습니다. 장마다 **PNG 저장**으로 한 장씩 받을 수도 있습니다.

## 기능 자세히 보기

### 웹 제작기

| 기능 | 설명 |
|---|---|
| 장 구성 | 속지 1~10장, 마무리 장(인스타그램 안내) 넣기/빼기, 속지 순서 이동(↑↓)·삭제 |
| 장별 구성 | **사진 1장** / **사진 2장** / **글만** (글만은 카드 안에 글을 크게 배치) |
| 표지 입력 | 윗 꼬리표, 제목(Enter로 줄바꿈), 해시태그, 표지 사진 |
| 속지 입력 | 소제목, 본문. `- `로 시작하는 줄은 글머리표(•), 그 다음 줄은 같은 항목의 이어지는 줄, 빈 줄은 문단 나눔 |
| 글 자동 맞춤 | 글이 영역보다 길면 글자 크기를 자동으로 줄이고, 그래도 넘치면 경고 표시 |
| 사진 한꺼번에 넣기 | 왼쪽 칸에 여러 장을 넣으면 표지부터 빈 사진 칸에 순서대로 배치 |
| 사진 조정 | 칸별 교체(클릭·끌어놓기), 미리보기에서 끌어 위치 이동, 확대 슬라이더, 가운데로, 빼기 |
| 저장 | 글은 브라우저에 자동 저장 (사진은 용량 때문에 저장하지 않음) |
| 새로 만들기 | 지금 내용과 사진을 모두 비우고 처음부터 |

### AI 자동 작성

- 모델: `claude-opus-5-5` (Anthropic Claude API, 사용자 키로 브라우저에서 직접 호출)
- 입력: 정보(자유 텍스트) + 사진 여러 장. 사진은 글자를 읽을 수 있도록 긴 변 1280px로 줄여 전송
- 출력: 표지 꼬리표·제목·해시태그, 속지 장 수(자동 1~10장 또는 지정), 장별 소제목·본문·구성·사진 번호
- 포스터·안내문 같은 자료 사진은 정보를 읽는 데만 쓰고, 카드에는 활동 사진을 우선 배치
- 모든 장에 사진을 넣지 않음. 맞는 사진이 없으면 글만 구성
- 결과는 화면에 바로 적용되고, 사람이 검토·수정해 최종본을 완성

### 피그마 연동

| 기능 | 설명 |
|---|---|
| 자동 연결 | 로컬 서버를 통해 웹 ↔ 플러그인 연결. 플러그인이 1.5초마다 새 작업을 확인 |
| 템플릿 채우기 | 표지(3-0)·속지(3-1)·마무리(3-7) 프레임을 복제해 글·글머리표·글자 크기를 웹 미리보기와 같게 적용 |
| 구성별 사진 칸 | 사진 1장/2장 구성에 맞게 사진 칸을 다시 만들고, 웹에서 조정한 위치·확대 그대로 잘라 넣음 |
| 진행 표시 | "받았어요 → 템플릿 찾는 중 → 3 / 7장 만드는 중…" 단계 표시, 1분 이상 멈추면 안내 |

| 파일로 넣기 | 서버 없이 쓸 때는 웹에서 받은 `카드뉴스_피그마용.json`을 플러그인의 "json 파일로 넣기"에 넣음 |

## AI 프롬프트 설계

`app.js`의 `AI_SYSTEM`(시스템 프롬프트)과 `AI_SCHEMA`(응답 형식)에 다음 기법을 적용했습니다.

1. **역할 지정** – "대학 교육혁신사업단 인스타그램 카드뉴스의 에디터"
2. **필드별 분량·형식 제약** – 템플릿 칸 크기에 맞춰 제목 2줄(줄당 10자 안팎), 소제목 20자, 본문 3~6줄(줄당 약 35자), "~합니다" 체
3. **예시 제시 (Few-shot)** – 제목·해시태그의 원하는 형태를 예시로 제시
4. **환각 방지 (그라운딩)** – 정보나 사진에서 확인되지 않는 날짜·숫자·이름·인용은 쓰지 않도록 지시
5. **멀티모달 입력 구조화** – 사진마다 `사진 0`, `사진 1` 번호를 붙여 보내고 번호로 배치하게 함
6. **조건부 규칙** – 맞는 사진이 없으면 글만 구성, 같은 사진 중복 금지, 장 수는 자동 또는 지정
7. **구조화된 출력** – JSON 스키마로 응답 형식 고정, 구성 값은 enum(`photo1`·`photo2`·`text`)으로 제한
8. **흐름 지정과 결과 검증** – 소개 → 진행 내용 → 의미·다음 계획 흐름, 잘못된 사진 번호는 후처리로 걸러 빈칸 없는 결과 보장

요청은 `effort: medium`으로 보내며, 안전 정책으로 거절될 때를 대비해 서버 측 대체 모델(`fallbacks: "default"`)을 켜 두었습니다.

## 폴더 구조

```
├─ index.html                  웹 제작기 화면
├─ app.js                      템플릿 렌더링, 편집, AI 자동 작성, 내보내기
├─ server.py                   로컬 서버 (웹 열기 + 웹→피그마 작업 전달)
├─ 카드뉴스 제작기 실행.bat      server.py 실행 바로가기
├─ assets/
│  ├─ bg-cover.jpg, bg-inner.jpg       표지·속지 배경 (피그마에서 추출)
│  ├─ footer-cover.png, footer-inner.png  하단 로고 띠
│  ├─ closing.png                      마무리 장
│  ├─ quote.svg                        따옴표 장식
│  └─ assets.js                        위 이미지를 data URI로 묶은 파일 (자동 생성)
├─ figma-plugin/
│  ├─ manifest.json            플러그인 정보 (localhost:8765 접속 허용)
│  ├─ code.js                  템플릿 복제·글·사진 채우기 (Figma Plugin API)
│  └─ ui.html                  플러그인 창 (서버 연결, 진행 표시, json 넣기)
└─ tools/
   └─ build_assets.py          assets.js 다시 만들기
```

## 동작 원리

```
[웹 제작기] ──정보·사진──▶ [Claude API] ──JSON──▶ [웹 제작기: 미리보기·편집]
                                                        │
                              PNG / ZIP 저장 ◀──────────┤
                                                        ▼
                       [로컬 서버 server.py] ◀── POST /api/job
                                │
                     GET /api/job?after=<id>
                                ▼
                     [피그마 플러그인] ──▶ 템플릿 복제·채우기
```

- **템플릿 재현**: 피그마 템플릿을 Figma MCP로 읽어 좌표·색·글꼴 크기를 `app.js`에 옮겼고, 브라우저 Canvas로 1080×1350 그대로 그립니다.
  배경 이미지는 `assets.js`에 data URI로 내장해, `index.html`을 파일로 바로 열어도 PNG 저장이 됩니다.
- **로컬 서버 API** (`127.0.0.1:8765`)
  - `POST /api/job` – 웹이 카드뉴스 데이터를 올림
  - `GET /api/job?after=<id>` – 플러그인이 새 작업을 가져감 (없으면 204)
  - `GET /api/status` – 마지막 작업 번호 (플러그인이 켜질 때 기준점으로 사용)
- **피그마로 보내는 데이터**: 장별 글, 구성, 웹에서 계산한 글자 크기, 칸 크기에 맞춰 잘라 낸 사진(2배 해상도 JPEG)

| 증상 | 해결 |
|---|---|
| 플러그인 창에 "웹 제작기가 꺼져 있어요" | `카드뉴스 제작기 실행.bat`을 켜 두었는지 확인 |
| 플러그인이 "만드는 중"에서 멈춤 | 플러그인을 닫고 다시 실행. 계속되면 캔버스 오른쪽 클릭 → 플러그인 → 개발 → 콘솔 보기에서 오류 확인 |
| "API 키가 올바르지 않아요" | Claude Console에서 발급한 `sk-ant-`로 시작하는 키인지, 크레딧이 남아 있는지 확인 |
| 고친 뒤에도 예전 화면이 보임 | 브라우저에서 Ctrl+F5 |
| 피그마 글꼴이 바뀌어 보임 | 그 컴퓨터에 Pretendard 글꼴이 없어 Noto Sans KR로 대체된 것. Pretendard 설치 후 다시 생성 |
| 새로고침하니 사진이 사라짐 | 사진은 브라우저에 저장하지 않으므로 다시 넣기 (글은 남아 있음) |

## 한계와 앞으로의 계획

**지금의 한계**
- 한 가지 템플릿에 맞춰져 있어, 다른 디자인을 쓰려면 코드 수정이 필요합니다.
- 피그마 플러그인은 개발자 모드로 설치해야 하고, 자동 연결은 웹과 피그마가 같은 컴퓨터에 있을 때만 됩니다.
- AI 기능은 API 사용료가 들며, 결과는 사람이 최종 검토해야 합니다.

**앞으로**
- 피그마 템플릿을 읽어 자동으로 등록해, 학생회·학과·동아리가 각자의 양식으로 쓰게 하기
- 웹을 온라인에 배포하고 플러그인을 조직에 공유해 설치 없이 쓰게 하기
- 인스타그램 게시글 본문·해시태그 생성, 문구 톤 선택, 작업 기록 저장
